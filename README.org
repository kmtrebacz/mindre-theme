* Introduction
My version of Mindre with my private modificatons

* Installation

*** Directly from this repo

#+begin_src emacs-lisp
(use-package mindre-theme
    :ensure t
    :straight (:host github :repo "kmtrebacz/mindre-theme")
    :custom
    (mindre-use-more-bold nil)
    (mindre-use-faded-lisp-parens t)
    :config
    (load-theme 'mindre t))
#+end_src
